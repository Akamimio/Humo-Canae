# Humo Canae – Zombie Defense
Lightweight English-language HTML5 PWA game. Open index.html to test locally; for install/offline features host over HTTPS (GitHub Pages).

## Controls
Move with A/D or Left/Right arrows. Aim with mouse/touch and hold click/touch or Space to shoot. Stop zombies before they reach the barricade. Three hits end the game.

## Publish
1. Create a GitHub repository and upload the CONTENTS of this folder to its root.
2. Enable GitHub Pages in Settings > Pages > Deploy from branch (main/root).
3. Test the GitHub Pages HTTPS URL on desktop and mobile.
4. Enter the URL in https://www.pwabuilder.com/ and generate a Windows package.
5. Test the package and complete Microsoft Partner Center requirements. Store approval is not guaranteed.

No external dependencies. No special Windows system permissions are needed by the web game itself. Windows packaging may add capabilities requiring review.
